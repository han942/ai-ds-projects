# 대회 회고록
전기차 가격(백만원)의 종속변수를 예측하는 대회.
## Feature 명목
- 제조사
- 모델
- 차량상태
- 배터리용량 (Nan,36%)
- 구동방식
- 주행거리(km)
- 보증기간(년)

## 주요 해결 프로세스
- Baseline 모델을 XGBoost로 잡음 => 결측치 처리를 하지 않기 위해서(NaN에 강한 모델)
- 종속변수와 상관관계가 높은 주행거리에서의 이상치 분석
  - IONIQ 모델의 이상치가 잡힘. => 모두 삭제(**중요**)
  - 반대로 '배터리용량'의 경우에는 이상치를 제거해도 성능 개선X
      - 이는 결측치 데이터 때문에 정상적인 분포가 모두 나타나지 않은듯...?

## 이상치 기준
- 차량상태 ↔ 주행거리가 서로 안 맞는 행을 잘라냄
  - Nearly New인데 5만km 초과
  - Pre-Owned인데 5만km 미만
- EDA에서 'Nearly New'와 'Pre-Owned'의 경계가 뭔지 계속 걸렸는데, 결국 주행거리로 갈리는 거였음
  - 근데 라벨이 그걸 안 지키는 행들이 섞여 있었고 그게 딱 이상치로 잡힘
- Brand New인데 주행거리가 0이 아닌 건 그냥 두기로 함 (거의 신형 정도로 해석)

## 모델별 성적 (5-fold CV RMSE)
| 모델 | 점수 | 메모 |
|---|---|---|
| RandomForest | 1.49 | 기준선 |
| XGBoost (기본값) | 1.473 | n_est 100, lr 0.3 |
| XGBoost + 이상치 제거 | 1.32 | 제일 크게 뛴 지점 |
| LightGBM (전처리X) | 1.357 | 아무것도 안 했는데 XGB보다 좋음 |

- 결국 점수를 움직인 건 모델이 아니라 데이터 쪽이었음. 모델 바꿔서 얻은 건 0.0x, 이상치 몇십 줄 지워서 얻은 건 0.15.
- LightGBM이 전처리 없이 1.357 나온 게 좀 허무했는데, 그만큼 XGB 쪽 세팅이 덜 다듬어졌다는 뜻이기도 함

## 안 통한 것들
전부 시도 → 점수 확인 → 롤백
- 배터리용량 결측치(36%) 채우기
  - 0으로 채우기: 1.48
  - train 평균으로 대체: 1.52 (제일 나빴음)
  - slinear 보간: 1.473 = 안 채운 거랑 동일
  - => 36%를 무슨 값으로 메꾸든 없는 정보가 생기진 않음. XGB에 NaN 그대로 넘기는 게 제일 나았다.
- 'run_dis' 파생변수 추가: 1.4673 (오차 범위)
- 종속변수 log1p 변환: skewness가 1 정도라 애초에 건드릴 이유가 없었음
- 스케일링: 트리 모델이라 당연히 의미 없음. 이건 안 해봐도 알았어야 했는데 습관적으로 돌림.
- 주행거리 + 배터리용량 이상치 동시 제거: 1.49 => 오히려 악화. 배터리용량은 결측이 많아서 분포 자체가 온전하지 않은데 거기서 이상치를 정의한 게 잘못.

## Optuna 튜닝
- n_estimators / learning_rate 두 개만 20 trial
- CV는 1.23까지 내려갔는데 실제 제출 점수는 튜닝 전보다 안 좋았음
- 나중에 objective 다시 보니 학습에 쓴 데이터로 그대로 예측해서 RMSE를 구하고 있었음
  - 그러니까 "train 오차를 최소화하는 파라미터"를 고른 셈. 과적합 방향으로 튜닝한 거라 CV 점수가 좋아 보인 게 당연.
  - hold-out을 eval_set에만 넘기고 score 계산에는 안 썼던 게 원인
- LightGBM objective도 `lgb_param`을 만들어놓고 정작 XGB의 `param`을 넘기고 있었음. 튜닝이 사실상 안 돌아간 상태였다.
- 최종 제출은 튜닝 파라미터 말고 기본값 + 이상치 제거 조합으로 냄 (`xgb_distance50000.csv`)

## 뒤늦게 발견한 것
- LabelEncoder를 train / test에 각각 `fit_transform` 함
  - 같은 제조사가 train과 test에서 다른 정수로 매핑됐을 수 있음
  - 다행히 카테고리 종류가 train/test에 다 있어서 큰 사고는 안 났지만, 원래는 train에서 fit한 인코더를 test에 transform만 해야 함
- LGBM + XGB 5:5 앙상블을 만들어두고 제출은 XGB 단독으로 함. 앙상블 점수를 안 재보고 넘어간 게 아쉬움.
