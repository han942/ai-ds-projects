# 대시보드 재생성

저장소 루트에서 실행합니다. Python 3.10 이상, 표준 라이브러리만 사용합니다.

```bash
python3 projects/Global_Supermarket_Analysis/dashboard_build/build_dashboard_data.py
python3 -m unittest discover -s projects/Global_Supermarket_Analysis/dashboard_build
```

빌더는 저장소의 `datafile/[DArt-B 5기] Global_Supermarket.csv`를 읽어
이 폴더의 `dashboard_data.json`과 `../dashboard.html`에 같은 데이터를 저장합니다.
경로는 스크립트 위치 기준으로 계산하므로 다른 작업 디렉터리에서도 실행할 수 있습니다.
HTML의 레이아웃·동작 코드는 유지하고 내장 데이터만 갱신합니다.

전체 기간 및 2019–2022 연도별 집계를 포함합니다. 원본 고객명·고객 ID·주문 ID는
HTML에 포함하지 않습니다. 대시보드는 서버·외부 폰트·CDN 없이 파일을 직접 열어 사용합니다.

## 지표와 필터

- 전체 필터: 분석 연도. KPI, 추이, 시장, 상품, 할인, 출고 차트에 동일하게 적용합니다.
- 상품 검색·정렬: 서브카테고리 차트에만 적용합니다.
- 월별 CSV: 선택 기간의 매출, 순이익, 주문 행 수를 내보냅니다.
- 주문 행 수: CSV 행 수이며 고유 주문 수가 아닙니다.
- 순이익률: `sum(profit) / sum(sales) * 100`.
- 고할인: `discount > 0.4`. 40%인 행은 제외합니다.
- 손실 기여도: 고할인 행의 음수 profit 합계 / 전체 음수 profit 합계.
- 출고 소요일: `ship_date - order_date`. 고객 수령일은 데이터에 없습니다.
- 제조사: `product_name`의 첫 단어로 추정. 검증된 제조사 분류가 아닙니다.
- 전략 검토 과제는 전체 기간 관찰에 기반한 가설로, 필터와 독립적입니다.

## 차트 설계

| 영역 | 비교 | 형태 | 집계 단위 |
|---|---|---|---|
| 매출·순이익 추이 | 시간에 따른 변화 | 선 | 전체 48개월, 연도 선택 시 12개월 |
| 시장·지역 | 순이익 규모 | 정렬된 가로 막대 | 시장 / 주문 지역 |
| 상품 | 서브카테고리 및 추정 제조사 손익 | 0 기준 양방향 막대 | 서브카테고리 / 상품명 첫 단어 |
| 할인 | 주문량 및 손실액 분포 | 세로 막대 | 하한 포함 10%p 구간 |
| 출고 | 배송 방식 및 출고 소요일 분포 | 세로 막대 | Ship Mode / 일 |

차트의 값은 요약 표기를 사용하며, 손익·추이 표에서는 정확한 금액을 표시합니다.
테마 전환 시 SVG는 CSS 변수를 따라 함께 갱신됩니다. 좁은 화면에서 차트는
내부 가로 스크롤로 글자 크기를 보존하고, 화면 전체에는 가로 스크롤을 만들지 않습니다.
