# Baseline: 후보 검색과 재정렬

질문: 현재 성능은 어떤 신호에서 나오며 지역에 얼마나 집중되는가?

**현재 판단: C1과 LightGCN의 결합은 후보 회수를 보완했다. LambdaRank의 test 재정렬 이득과 전국 취향 추천은 확인하지 못했다.**

## 결과

| 구성 | Test Recall@100 | NDCG@10 |
|---|---:|---:|
| C1 공동 방문 후보 순서 | 17.8127% | 0.023961 |
| C4 LightGCN 후보 순서 | 18.7510% | 0.021563 |
| C5: C1+C4 RRF 후보 순서 | 20.1626% | 0.026590 |
| 같은 C5 후보 → LambdaRank | 20.1626% | 0.025467 |

2026-10-04~05, snapshot `e7896add5b4b5939`, Window 학습·history-aware 만족도·최소 이력 10건, seed=42, 후보 K=100, 주 지표 test 사용자 1,573명이다. 입력·정답 정의와 현재 모델은 [BASELINE_MODEL](../BASELINE_MODEL.md)에 있다.

## 해석

C5−C1 Recall 차이는 +2.35%p [1.22, 3.43]%p, C5−C4는 +1.41%p [0.27, 2.52]%p였다. C4 단독과 C1 단독의 차이 구간은 0을 포함한다. LambdaRank−C5 순서의 NDCG 차이 −0.001124도 구간이 0을 포함한다.

지역 피처의 gain 비중은 7.25%지만 성능 기여율을 뜻하지 않는다. 제거 재학습의 NDCG는 0.025467→0.024286이며 차이 구간은 0을 포함한다. 주 활동 지역 비중은 C5 Top-10 82.24%, LambdaRank 84.14%, 지역 피처 제거 후에도 78.57%다. 지역은 방문·공동 방문 신호에도 담길 수 있다.

보조 pair 50.88%는 후보 안의 미래 relevance가 다른 식당쌍 91명·234쌍에 대한 사용자 평균이며 전체 추천 정답률이 아니다. 구간 [42.30%, 60.18%]는 무작위 기대값 50%를 포함한다.

과거 Prefix/절대 등급의 shrinkage λ=10은 test NDCG 0.029360→0.028207로 개선을 확인하지 못했다. Validation은 0.025151→0.027881이었다. 현재 Window/개인별 정답과 직접 비교하지 않는다.

## 왜 리뷰 모델보다 강하게 나타나는가

같은 방문 그래프에 텍스트 정렬만 추가하는 후속 비교도 완료했다. RLMRec-Con/E5 적응판의 가중치·shuffle·전체 ranker 재학습 결과는 [리뷰 임베딩 리포트](./review_embeddings.md#rlmrec-방식으로-베이스라인에-텍스트를-결합한-비교)에 있으며, 일관된 개선을 확인하지 못해 이 baseline을 유지한다.

2026-10-10 사용자 요청으로 코드와 저장된 validation 순위를 다시 확인했다. **기준 모델은 공동 방문 관계를 직접 활용하며, 새 리뷰 Transformer는 그 점수·학습된 그래프 표현을 이어받지 않았다.** 이 차이가 성능 격차에 얼마나 기여했는지는 대조 학습을 하지 않아 미확정이다.

| 같은 validation | Recall@100 | NDCG@10 |
|---|---:|---:|
| C1 공동 방문 유사도 | 16.5149% | 0.021895 |
| C4 LightGCN | 19.2869% | 0.020708 |
| C5: C1+C4 순위 결합 | 19.4769% | 0.023311 |
| 같은 C5 → 기존 16피처 LambdaRank | 19.4769% | 0.027694 |

LambdaRank의 0.027694는 같은 validation에서 7개 설정을 비교해 선택한 `num_leaves=63`, `min_child_samples=100`, 76 trees의 값이다. 미조정 reference는 0.024387이었다. Baseline도 설정을 선택한 모델이므로 독립 holdout에서 확정된 점수로 해석하지 않으며, 새로운 Transformer의 고정 설정 하나와 탐색 예산까지 같았던 비교는 아니다. [선택 기록](../artifacts/comparisons/review_ltr/20261007T060016724659Z-e7896add/selection.json).

C1의 유사도는 리뷰 의미 유사도가 아니라 `두 식당에 모두 방문한 사용자 수 / sqrt(각 식당의 방문 사용자 수 곱)`이다. 사용자별 과거 방문 식당과 후보의 유사도를 합산한다. 평점이 낮았던 방문도 공동 방문 관계에 들어가며, 문장·맛·서비스의 유사성을 직접 측정하지 않는다.

LightGCN은 cutoff 이전의 모든 고유 사용자–식당 방문 간선을 사용하고, 이웃 표현을 3층 전파해 점수를 학습한다. C1이 직접 공동 방문 이웃을 세는 방식이라면 LightGCN은 그래프를 거친 관계를 학습하는 방식이다. 일반적인 전파 구조는 [LightGCN 원 논문](https://arxiv.org/abs/2002.02126)을 따르며 현재 구현의 입력은 방문 간선이다.

C1→C5에서 기존 Top-100 정답 쌍 195개가 빠지고 새 정답 쌍 341개가 들어왔다. Recall 순증가 +2.9620%p의 paired 95% 구간은 [+1.9910, +3.9052]%p다. 그러나 C5−LightGCN Recall 차이는 +0.1900%p, 구간 [−0.9199, +1.2980]%p로 0을 포함한다. 상호 보완은 관측됐지만 결합이 LightGCN 단독보다 항상 좋다고 단정하지 않는다.

현재 정답은 미래 기간의 실제 방문 중 개인별 만족도 기준을 넘은 식당이다. 공동 방문은 활동 지역·접근성과 선호를 함께 반영할 수 있어 이 평가 목표와 맞을 가능성이 있다. 어느 요인의 기여가 큰지는 아직 분리하지 않았다. 후보 100개에서도 정답 회수율은 약 19.5%이므로 기준 모델에도 개선 여지가 남아 있다.

새 Transformer의 ID는 무작위로 초기화한 별도 embedding이며, LightGCN 전파·초기화·공동 방문 점수 입력을 사용하지 않는다. 과거 시간창의 적격 후속 양성으로 학습한 사용자도 전체 ID 11,655명 중 4,705명이다. 이 모델과 baseline의 비교는 텍스트 유무 외에 행동 표현·학습 목표·대상·후보까지 달라 텍스트의 추가 효과를 분리하지 못한다. 동일 행동 후보·점수를 유지한 [본문 추가효과 비교 설계](./review_embeddings.md#베이스라인을-유지한-텍스트-추가효과-검증)를 다음 가설로 둔다.

이번에는 저장된 validation 1,645명 중 정답이 있는 1,639명의 지표와 후보 유입·탈락만 다시 계산했다. 새 학습·예측·test 분석·API는 없다. [이번 재검산](../artifacts/diagnostics/baseline_text_context_audit.json)과 [기존 paired 비교·순위 결합 감사](../artifacts/diagnostics/validation_rrf_signal_audit.json)가 근거다.
