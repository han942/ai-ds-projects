# 리뷰 속성: 표현과 평점

**연구 질문**

- 리뷰에서 추출한 표현과 같은 사용자의 평점 순서 사이의 관계

**현재 판단: 같은 리뷰의 평점과 연결되는 신호는 확인했지만, 미래 추천 성능은 검증하지 않았다.** v3 추출·평점 진단은 완료했고, 근거 위치를 보완한 v4는 코드 검증·입력 준비까지만 완료했다.

1. v3 실제 추출

   - 고활동 사용자 15명
   - 리뷰 2,139개와 평점 비교
   - 미확인: 전체 사용자 대표성과 미래 식당 추천 정확도

2. v4 구현·입력 준비

   - 문장 번호 선택 방식
   - 원문 구간·hash 검증
   - 미확인: 새 API 추출, 표본 검토, 동일 리뷰의 v3/v4 품질 비교

## 비교 조건과 진단 방법

2026-10-06 snapshot `e7896add5b4b5939`에서 이력 수 상위 15명의 텍스트 리뷰 2,139개를 분석했다. 낮은 평점 리뷰도 포함했으며 OpenRouter 무료 Nemotron 3 Super를 사용했다. 임베딩 생성이나 추천 모델 학습은 수행하지 않았다.

1. 추출 입력

   - 리뷰 원문만 전달
   - 실제 평점·사용자·식당의 별도 필드는 미전달

2. 추출 내용

   - 맛·가성비·서비스·분위기·양
   - 재방문 의향
   - 원문 근거

3. 비교 점수

   - 언급 속성 5개 평균
   - 전체 만족 표현
   - 재방문 의향은 속성 평균에서 제외

4. 평점 연결

   - 같은 사용자 내 실제 평점이 다른 리뷰 쌍의 순서 비교

5. 집계

   - 감정 점수 동점은 0.5점
   - 리뷰 쌍 일치율을 사용자별로 계산한 뒤 평균

## 결과와 한계

| 표현 | 점수가 있는 리뷰 | 사용자 평균 Spearman | 리뷰 쌍 순서 일치 | 95% 구간 |
|---|---:|---:|---:|---|
| 언급 속성 5개 평균: 재방문 제외 | 2,089 | 0.507 | 74.2% | 71.1~77.4% |
| 전체 만족 표현 | 2,012 | 0.538 | 74.8% | 71.5~77.8% |

**74.2%는 미래 식당 추천 정확도가 아니다.** 같은 리뷰의 표현과 이미 부여된 평점 사이의 사후 진단이며, 고활동 15명에 한정된 결과다. 전체 만족과 속성 평균을 같은 리뷰에서 비교한 차이 구간도 0을 포함해 어느 쪽이 더 낫다고 확정하지 않는다.

| 확인한 문제 | 해석의 한계 |
|---|---|
| 원문과 다른 인용 의견 229개 | unknown으로 제외했으며 남은 추출이 모두 정확하다는 보장은 없음 |
| 대기 불만 누락·재방문 과잉 추론 | v4 프롬프트 보완의 근거이나 수정 효과는 아직 미측정 |
| Codex의 별도 30개 표본 검토 | 사람 정답 라벨을 이용한 품질 검증은 아님 |

위 표는 **v3 실행 결과**다. v4에서 근거 위치를 검증하는 동작과 감정 해석의 정확성은 별개다.

## 근거 추출 v4 보완

v4는 인용문을 생성하는 대신 같은 리뷰의 `sentence_id` 1~2개를 선택한다. 코드가 해당 원문 전체를 복원해 번호와 문자 위치를 남긴다. 줄바꿈·문장부호에 따른 결정적 구간 분할이며 언어학적 문장 분석은 아니다.

| 보완 | 처리와 검증 |
|---|---|
| 근거 번호 | 없는 번호·중복·비정수 번호는 unknown; 원본 응답과 제외 이유 보존 |
| 별점 표현 | 마스킹 부분을 독립 구간으로 분리; 이를 포함한 근거는 unknown으로 제외 |
| 원문 보존 | 긴 문장의 부정·대조 표현과 인접한 의견을 자르지 않음 |
| 위치 계약 | 마스킹한 `extraction_text`의 Python 문자 인덱스 `[start, end)` |
| 감정 프롬프트 | 대기·웨이팅은 서비스에서 확인하고 재방문은 명시적 의향만 인정 |
| 버전 분리 | v3는 `--analyze-only`로 재분석; v4는 새 출력 폴더 사용 |

API에는 review_id와 번호가 붙은 원문만 전달하며 별도 평점·사용자·식당 필드는 보내지 않는다. 관련 테스트 27개를 통과했고 실제 2,139개 리뷰의 입력과 원문 구간 7,522개의 위치·텍스트·hash를 검증했다. 별점 마스킹 구간 23개를 제외해도 모든 리뷰에 선택 가능한 근거가 남았다. **이 준비·검증에는 API 호출이 없었다.**

## 다음 작업과 실행 방법

다음 단계는 v4 실제 추출, 표본 검토, 동일 리뷰에서의 v3/v4 비교다. 근거 좌표의 정확성과 감정 해석의 정확성을 나눠 확인한 뒤 추천 입력으로 쓸 수 있는지 판단한다. **이 v4 추출기를 연결한 추천 모델은 아직 실행하지 않았다.** 별도 규칙 기반 의견 추출의 10채널 추천 실험은 [임베딩 리포트](./review_embeddings.md#속성감정-채널과-여러-취향-후보-비교)의 다른 경로다.

프로젝트 루트에서 입력만 준비하는 명령이다. `--prepare-only`를 빼면 새 API 추출을 실행하며, 완료 후 `--analyze-only`로 그 캐시를 재분석할 수 있다.

```bash
python -m rating_recsys.experiments.review_aspect_audit \
  --output artifacts/review_aspects/20261006_top15_sentence_v4 \
  --users 15 --batch-size 20 --concurrency 2 --prepare-only
```
