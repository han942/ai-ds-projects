새 비교: **C5 후보는 고정하고 Nemotron 리뷰 의미 유사도를 LambdaRank 피처로 추가한다.** 구현·로컬 검증은 완료했고, 2026-10-07 사용자 요청으로 실제 추출을 보류했다. 부분 캐시는 보존했으며 전체 추출과 추천 성능 평가는 미완료다. [LTR 비교 조건·실행 상태](./review_ltr.md).

**현재 판단: Liquid 문서 임베딩 조건은 미채택. 개별 리뷰 집계 비교는 API 한도로 미완료.**

2026-10-04 완료 실험은 OpenRouter `liquid/lfm-2.5-embedding-350m:free`의 1,024차원 벡터를 사용했다. 최근 4점 이상 사용자 리뷰 최대 5개·식당 리뷰 최대 10개를 각각 한 문서로 묶었다. 리뷰당 240자, 문서당 최대 500토큰으로 제한했으며 test 프로필 35.25%가 토큰 예산에 의해 잘렸다.

같은 snapshot `e7896add5b4b5939`, validation 입력 ≤2025-12-19, test 입력 ≤2026-05-04, 후보 K=100, seed=42, 주 지표 test 사용자 1,573명을 사용했다. 후보 검색만 평가했으며 LambdaRank는 재학습하지 않았다.

선택 결합의 C5 대비 Recall 차이는 −3.5989%p, 95% 구간 [−4.4422, −2.8003]%p다. 리뷰 묶기·잘림·의미 유사성과 선호의 차이는 가능한 원인이지만, 집계 대조가 미완료이므로 원인으로 확정하지 않는다. 로컬 CPU 모델 파일 준비도 완료된 추천 평가로 취급하지 않는다.
