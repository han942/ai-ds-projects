## 현재 판단

현재 결론은 행동 기반 C5를 유지하는 것이다. 리뷰 텍스트에서 일부 신호는 확인했지만, 동일 조건의 통제 비교와 불확실성 구간까지 고려하면 기준 모델을 바꿀 근거는 아직 부족하다.

1. 기준 모델

   - C1 공동 방문 + C4 LightGCN의 RRF(C5)
   - 후보 100개를 LambdaRank로 재정렬

2. 리뷰의 추가효과

   - 여러 접근을 실행했으나 행동 기준의 안정적인 보완 이득 미확인
   - 기준 모델에는 리뷰 미사용

3. 현재 후속

   - 전체 식당 후보 검색
   - 재정렬 연구는 보류

4. 최근 수정

   - 10월 12일 코드 오류 6개 수정
   - 전체 테스트 512개 통과, 1개 skip
   - 수정 후 실데이터 성능 미측정

## 대표 결과 비교 기준

1. 기준 모델 test, seed 42

   - C5 Recall@100: **20.1626%**
   - C5 후보 NDCG@10: **0.026590**
   - LambdaRank NDCG@10: **0.025467**
   - 재정렬 이득 미확인

2. 같은 C5의 E5 LTR test

   - 기존 LambdaRank: **0.025467**
   - E5 6피처: **0.025570**
   - 차이 구간에 0 포함

3. 동일 Two-Tower validation, 3seed 평균

   - 행동만 Recall@100: **9.1229%**
   - 행동+텍스트: **9.3854%**
   - 추가효과 미확인

4. 그래프·학습 리뷰 validation, 3seed 평균

   - 행동 C4: **18.4481%**
   - 실제 텍스트 그래프: **18.2001%**
   - 균형 교정 late: **18.4514%**
   - 기준 모델 유지

5. RQ-VAE 표현 audit

   - Payload: **144.63배 축소**
   - 원래 Top-10 이웃 overlap: **10.42%**
   - 추천 개선 미확인

- 평가 기간·seed·학습 목표가 다른 항목을 하나의 성능 순위로 합치지 않는다.
- 후보 순서 NDCG와 최종 재정렬 NDCG를 구분한다.
- 정확도 분모는 validation 1,639명, test 1,573명이다.
- 신규 사용자 효과는 아직 평가하지 않았다.

## 후속 과제

1. 수정 코드 영향 검증

   - 별도 validation에서 수정 전후 비교
   - 코드 수정 완료를 성능 개선으로 해석하지 않음

2. 미래 만족도 목표

   - 같은 행동 모델 유지
   - 실제 텍스트와 shuffle 대조
   - 미래 방문·만족도에 맞춘 텍스트 학습

3. 표현 진단

   - 방향 집중
   - 후보 유입·탈락
   - 비용과 coverage

4. 독립 시간 검증

   - 과거 rolling validation 또는 새 미래 holdout
   - 기존 test를 새 설정 선택에 재사용하지 않음

원 설정·학습 곡선·모델·순위·검산은 각 리포트가 연결하는 artifact에 있다. DeepCoNN·Liquid·RQ-VAE 일부 원본은 현재 접근할 수 없으므로 문서 기록과 직접 재검산 범위를 구분한다. [파일 보존·복원 안내](../artifacts/README.md)를 따른다.
