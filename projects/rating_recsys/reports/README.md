## 현재 판단

**현재는 행동 기반 C5를 유지하고, 리뷰를 이용한 후보 검색 개선에 집중한다.** 리뷰 안에서 비슷한 내용을 찾는 신호는 확인했지만, 그 신호가 사용자의 미래 방문·만족도를 더 잘 맞히는 일관된 효과는 아직 확인하지 못했다. 텍스트 단독 모델이 좋아졌다는 결과와 강한 행동 모델을 보완했다는 결과를 구분해서 읽어야 한다.

C5는 공동 방문 검색과 LightGCN 검색의 순위를 합쳐 후보를 만든다. LambdaRank는 그 후보 안의 순서를 바꾸므로 후보에 없는 정답 식당을 새로 추천할 수 없다. 이 때문에 현재 후속은 후보 100개에 더 많은 정답을 담는 retrieval에 우선순위를 둔다.

- 기준 모델: C1·C4의 RRF(C5)로 후보 100개를 찾고 LambdaRank로 재정렬한다. 리뷰는 기준 모델에 미사용이다.
- 현재 후속: 리뷰를 이용한 전체 식당 후보 검색. 재정렬 연구는 보류한다.
- 코드 수정: 10월 12~13일 오류·재개 기능을 보완했다. 검증과 실데이터 성능 측정은 [수정 기록](./review_embeddings.md#중단-재개부정어-경계-2026-10-13)에서 구분한다.

## 대표 결과 비교 기준

아래 표는 각 실험의 주된 판단을 찾기 위한 요약이다. 행마다 평가 기간과 비교 질문이 달라 전체 모델의 성능 순위로 사용하지 않는다. 상세 표에서는 같은 조건 안의 차이와 신뢰구간을 함께 본다.

| 비교 질문 | 평가 조건 | 대표 결과 | 판단 |
|---|---|---|---|
| 후보를 찾은 뒤 순서를 더 잘 정했는가? | 기준 test, seed 42 | C5 Recall@100 20.1626%; NDCG@10은 C5 0.026590 → LambdaRank 0.025467 | 재정렬 이득 미확인 |
| 같은 후보에서 E5 feature가 추가 이득을 주는가? | 같은 C5의 LTR test | NDCG@10 0.025467 → 0.025570 | 차이 구간에 0 포함 |
| 같은 모델에 텍스트만 더하면 좋아지는가? | Two-Tower validation, 3seed 평균 | Recall@100 9.1229% → 9.3854% | 추가효과 미확인 |
| 행동 그래프와 리뷰 표현의 결합은 도움이 되는가? | Graph/review validation, 3seed 평균 | 행동 C4 18.4481%, 실제 텍스트 그래프 18.2001%, 교정 late 18.4514% | 행동 기준 유지 |
| 압축 후에도 검색에 필요한 차이가 남는가? | RQ-VAE 과거 표현 audit | Payload 144.63배 축소; 원래 Top-10 이웃 overlap 10.42% | 압축과 추천 개선은 별도 |

차이 구간이 0을 포함한다는 것은 이번 데이터로 개선 방향을 확정하기 어렵다는 뜻이다. 두 방법이 같다는 증거나 텍스트에 유용한 정보가 없다는 결론은 아니다. 작은 점수 상승보다 실제 텍스트 대응과 shuffle의 차이, 같은 구조의 텍스트 유무 대조를 우선 확인한다.

- 평가 기간·seed·학습 목표가 다른 항목을 하나의 성능 순위로 합치지 않는다.
- 후보 순서 NDCG와 최종 재정렬 NDCG를 구분한다.
- 정확도 분모는 validation 1,639명, test 1,573명이다.
- 신규 사용자 효과는 아직 평가하지 않았다.

## 후속 과제

1. 수정 코드 영향 검증

   - 별도 validation에서 수정 전후 비교
   - 코드 수정 완료를 성능 개선으로 해석하지 않음

2. 미래 만족도 목표

   - 같은 행동 모델 유지
   - 실제 텍스트와 shuffle 대조
   - 미래 방문·만족도에 맞춘 텍스트 학습

3. 표현 진단

   - 방향 집중
   - 후보 유입·탈락
   - 비용과 coverage

4. 독립 시간 검증

   - 과거 rolling validation 또는 새 미래 holdout
   - 기존 test를 새 설정 선택에 재사용하지 않음

원 설정·학습 곡선·모델·순위·검산은 각 리포트가 연결하는 artifact에 있다. DeepCoNN·Liquid 등 일부 원본의 접근 가능 여부는 자료별로 다르므로 문서 기록과 직접 재검산 범위를 구분한다. 이 로컬의 RQ-VAE run은 보존돼 있으며 이번에는 새 재검산을 하지 않았다. [파일 보존·복원 안내](../artifacts/README.md)를 따른다.
