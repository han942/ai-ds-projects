# 실험 overview

카테고리마다 짧은 overview 하나를 유지한다. 무엇을 비교했고 무엇을 채택했는지 확인하는 문서이며, 실행별 상세 로그를 누적하는 문서가 아니다.

| 카테고리 | Overview | 현재 상태 |
|---|---|---|
| BM25·한국어 토큰화·전처리 | [BM25](./bm25.md) | 완료, 이번 조건 미채택 |
| OpenRouter 리뷰 임베딩·집계 | [리뷰 임베딩](./review_embeddings.md) | 문서 임베딩 완료·미채택, 개별 집계는 한도 중단 |
| LLM 리뷰 속성 추출 | [리뷰 속성](./review_aspects.md) | 선행 진단 완료, 추천 결합 미실행 |
| Baseline·협업·지역·평점 보정 | [Baseline 진단](./baseline.md) | 현재 기준과 진단 정리 |
| Jev 재랭킹 | 실행 결과가 생기면 overview 작성 | 계획, 미실행 |

각 overview에는 질문·비교 조건·핵심 결과·현재 판단·근거 위치를 남긴다. 같은 카테고리의 새 결과가 나오면 현재 판단과 표를 갱신하고, 이전 상세 기록은 보관한다. 하나의 `EXPERIMENTS.md`에 모두 누적하지 않는다.

미채택 실험도 시도한 조건과 결과는 overview에 짧게 남긴다. 재현할 가치가 있는 상세 자료는 로컬 ZIP에 보관하고 Git에는 올리지 않는다. 복원 가치가 없는 임시 파일·중복 출력은 정리할 수 있다. 모델 전체의 폐기와 특정 설정의 미채택을 구분한다.

현재 기준 모델의 정의는 [BASELINE_MODEL](../BASELINE_MODEL.md), 실험 계획은 [PLAN](../PLAN.md), 보관·복원은 [실험 파일 안내](../artifacts/README.md)에 있다. 이번 정리는 새 실험이나 API 호출을 포함하지 않는다.
