# Analysis 기록과 정리 기준

이 폴더는 데이터 품질 점검과 오프라인 실험의 **완료된 결과**를 남긴다. 추천
파이프라인의 실행 입력이나 Python 패키지의 일부가 아니다. 현재 실행 코드와
설정은 `src/rating_recsys/`, 실행별 원본 결과는 `artifacts/runs/`에 있다.

## 파일을 남기는 기준

1. 점검 또는 실험이 끝나면 날짜가 포함된 Markdown 문서에 사용한 데이터
   스냅샷, 평가 방법, 핵심 수치, 해석의 한계, 재실행 명령과 결과 경로를 남긴다.
2. 그 문서로 결론을 확인할 수 있고 실행 코드는 `src/` 또는 `crawler/`에
   있다면, 일회성 노트북·스크립트와 그 노트북이 만든 중복 HTML·이미지·JSON은
   삭제한다. 진행 중인 파일은 목적과 삭제 조건을 이 문서에 먼저 기록한다.
3. 결과 문서를 삭제하거나 옮길 때는 `README.md`와 `BASELINE_MODEL.md`의
   링크를 함께 고친다. 이전 스냅샷의 수치를 현재 성능으로 표시하지 않는다.

## 현재 보존하는 결과

| 문서 | 상태 | 남기는 이유 |
|---|---|---|
| `candidate_k_2026-09-21.md` | 완료 · 과거 스냅샷 | 후보 K와 평가 대상 사용자 범위의 초기 판단 |
| `region_ablation_2026-09-23.md` | 완료 · 과거 스냅샷 | 지역 후보·feature 제거 비교 근거 |
| `lightgcn_candidate_2026-09-23.md` | 완료 · 과거 스냅샷 | LightGCN 후보 실험 근거 |
| `crawler_import_2026-09-26.md` | 완료 · 적재 기록 | 전국 크롤링 중간 스냅샷의 출처와 품질 |
| `data_snapshot_2026-09-27.md` | 완료 · 조회 시점 | 이전/현재 데이터 규모 비교 |
| `baseline_2026-09-27.md` | 완료 · 새 스냅샷 | 2단계 기준선 재측정 결과 |

`candidate_k_analysis.ipynb`, `diningcode_review_quality.ipynb`와 그 생성 파일의
결론은 위 문서에 옮겼다. `compare_current_data.py`는 2026-09-27 비교에만 사용했고
현재 데이터 규모는 프로젝트 `README.md`에 기록했다. 이 파일들은 실행을
마쳐 삭제했다. 새 데이터의 기준선 결과는 `baseline_2026-09-27.md`에 남겼다.

현재 진행 중인 분석 노트북이나 일회성 스크립트는 없다.
