# 전국 Playwright 크롤링 중간 스냅샷 Supabase 적재

2026-09-26 현재 `crawler/data`에 있는 **미완료** national crawl의 CSV를 변경 불가능한 파일로 복사하고, Supabase `recsys` 스키마에 적재했다. 원본 `.csv.partial`과 checkpoint는 수정하지 않았다. Checkpoint는 `crawl_complete=false`이며, 이 결과를 전체 수집 완료량으로 해석하면 안 된다.

## 구분 방법

기존 5개 파일은 `recsys.crawl_runs.source = 'diningcode'`, 이번 파일은 **`source = 'diningcode_playwright_national'`**이다. 리뷰마다 `crawl_run_id`가 있어 출처를 조인할 수 있다. 이번 고정 스냅샷의 run ID는 `b22dcc90-6dfc-46eb-a967-05e7406373a9`이다. 식당·사용자 테이블은 공유하지만, 이번 적재는 기존 식당·사용자 행을 갱신하지 않고 새 키만 삽입했다. 겹치는 리뷰는 `content_hash`로 건너뛰므로 기존 run에 남는다.

조회 SQL: [compare_crawl_sources.sql](../../queries/compare_crawl_sources.sql). 기존/새 데이터만 모델에 사용하려면 `recsys.reviews`를 `recsys.crawl_runs`와 `crawl_run_id`로 조인해 `cr.source`를 필터링해야 한다. 현재 기본 데이터셋 조회는 전체 출처를 함께 읽는다.

## 적재 및 품질 확인

| 항목 | 건수 |
|---|---:|
| CSV 물리 행 | 82,966 |
| 필수값 통과 | 82,889 |
| 필수값 누락으로 제외 | 77 (0.09%) |
| 기존 DB 리뷰와 중복 | 9,174 (통과 행의 11.07%) |
| 신규 삽입 리뷰 | **73,715** |
| 적재 전 기존 리뷰 | 23,207 |
| 적재 후 전체 리뷰 | **96,922** |

제외 사유는 주소 누락 68건, 사용자명 누락 9건이다. 새 리뷰는 식당 4,298개, 사용자 12,624명에 연결됐다. 새 리뷰의 날짜 precision은 exact 56,616건, inferred year 16,725건, relative 372건, unknown 2건이다. 식당 지역이 `전국`으로 남은 새 리뷰는 338건(0.46%)이다. 리뷰 날짜가 수집일보다 미래인 행과 DB의 중복 `content_hash`는 각각 0건이다. 기존 출처에 연결된 23,207건의 리뷰 수는 적재 전후 동일하다.

원본 파일의 CSV 행 수 82,966은 checkpoint의 `total_unique_review_rows=65,004`와 다르다. Checkpoint의 의미나 갱신 시점을 확정할 근거는 없으므로 **고정된 CSV 스냅샷의 실제 행 수**를 적재 모수로 사용했다. 원본은 2026-09-24~26 사이에 수집됐고, 일부 상대 날짜는 각 행의 `crawl_timestamp` 기준으로 해석했다. 원본 파일명의 6자리 시각, 주소의 시·도 prefix도 이번 형식에 맞춰 변환했다.

`content_hash`는 기존처럼 날짜 원문·평점·리뷰 문구 등을 사용한다. 같은 실제 리뷰라도 날짜 표시가 바뀌면 다른 hash가 될 수 있으므로 9,174건은 확실한 중복 수이며 실제 중복의 상한이라고 볼 수 없다. 나중에 crawl이 재개되어 CSV가 늘면 같은 명령을 다시 실행해 **새 스냅샷을 별도 run으로 적재**할 수 있다. 기존 hash는 다시 삽입되지 않는다.

## 추출 정확성 재점검 (2026-09-26)

전국 스냅샷 적재 전인 2026-09-23에 성심당 본점의 별도 단일 식당 수집 파일도
점검했다. 페이지에는 평가 364건이 표시됐으나 71회 더보기를 누른 뒤 확인된
카드는 356건이었다. 카드의 리뷰 ID는 모두 고유하고 작성자명·평점·날짜가
채워져 있었으며 본문만 비어 있는 카드가 16건이었다. 남은 8건 차이의 원인은
확인되지 않아 당시 CSV와 체크포인트는 미완료로 보존했다. 이 표본 수치는
아래 전국 스냅샷의 적재 건수에 더하지 않는다.

체크포인트에 등록된 식당 11,773개 중 `complete` 3,701개, `incomplete` 615개, `running` 4개, `pending` 7,453개다. 완료 판정 식당 3,701개는 모두 페이지의 표시 평가 수 이상을 수집했다. 미완료 식당 615개는 표시 평가 수에 비해 **합계 1,224건 부족**하고, 그중 370개는 1건씩 부족하다. 사이트의 표시 수와 실제 공개 카드 수가 항상 같은지는 단정할 수 없으므로 이 수치를 확정된 누락 리뷰 수로 해석하지 않는다. 다만 전국 수집의 완전성은 입증되지 않았다.

CSV 82,966행은 19개 헤더와 행 구조가 모두 일치하고, `restaurant_id`와 `source_url`의 `rid`가 82,966행 전부 일치한다. 같은 `restaurant_id`가 서로 다른 식당명·주소로 나타난 경우는 없다. 리뷰 본문이 비어 있는 행은 2,440건(2.94%)으로 1,284개 식당에 퍼져 있으며, 모든 본문이 빈 식당 2곳은 각각 리뷰가 1건뿐이다. 본문 확장 미완료 표시는 13건이다. 이 상태는 텍스트 없는 평점일 수도 있으므로 모두 추출 오류로 분류할 수는 없다. 날짜만 제외한 `(식당 ID, 사용자명, 평점, 본문)` 중복은 37행이다.

현재 공개 페이지 2곳을 robots 정책을 지키며 읽기 전용으로 재확인했다. 완료 판정 식당은 페이지 표시 25건, 현재 DOM에서 읽힌 25건, 저장 CSV 25건이었고 **본문·평점·사용자명 조합 25건이 일치**했다. 미완료 판정 식당은 페이지 표시 22건에 대해 현재 DOM에서 읽힌 20건과 저장 CSV 20건이 **모두 일치**했다. 따라서 이 두 표본에서 저장된 카드 내용은 정확했지만, 표시 수와 실제 접근 가능한 카드 사이의 2건 차이는 남아 있다. 두 페이지의 작은 표본으로 나머지 식당의 내용 정확성을 보증하지 않는다.

체크포인트 `total_unique_review_rows=65,004`는 현재 CSV의 82,966행보다 작다. 이 값은 크롤러 종료 단계에서 다시 계산되는 값이므로 중단된 실행의 현재 행 수로 사용하지 않는다. 현재 총량은 CSV를 직접 읽은 값으로 보고한다. 앞으로 크롤을 재개할 때는 대기 식당을 처리하고 미완료 식당의 표시 수 차이를 별도로 검증해야 한다.
