# 데이터 스냅샷 변화 (2026-09-27 조회)

2026-09-21 실행의 입력 스냅샷(`03a76325`, 23,017건)과
2026-09-27 Supabase `recsys` 스키마의 읽기 전용 집계를 비교했다. 현재 DB에는
미완료 전국 Playwright 크롤링의 2026-09-26 중간 스냅샷이 포함된다. 이 수치는
조회 시점의 데이터 규모이며 새 모델의 품질 지표가 아니다.

| 항목 | 이전 스냅샷 | 2026-09-27 DB |
|---|---:|---:|
| 원본 리뷰 | 23,207 | 96,922 |
| 최초 사용자·식당 상호작용 | 23,017 | 88,554 |
| 사용자 | 6,987 | 14,008 |
| 식당 | 748 | 4,587 |
| 고유 식당 3곳 이상 사용자 | 2,396 | 5,934 |
| (보관) leave-last-two-out train / validation / test | 12,504 / 2,396 / 2,396 | 66,669 / 5,934 / 5,934 |
| 전역 cutoff train / validation / test | – | 70,883 / 8,934 / 8,737 |

전역 cutoff 분할(현재 평가 방식)은 interaction 날짜의 80%·90% 지점을 기준으로
train ~ 2025-12-19, validation ~ 2026-05-04, 그 이후를 test로 둔다. Leave-last-two-out
행은 [보관한 이전 평가 방식](../archive/primary/README.md)의 분할 규모다.

원본 리뷰 96,922건은 기존 `diningcode` 23,207건과
`diningcode_playwright_national` 73,715건이다. 사용자·식당 쌍의 최초
방문만 남기면 88,554건이 된다. 두 출처에 모두 나타난 사용자 5,603명,
식당 459곳, 사용자·식당 쌍 7,368개를 확인했다. 현재 모델링 조회는 두
출처를 함께 사용한다.

이전 실험과 비교해 사용자 집단과 식당 catalog가 모두 달라졌으므로,
이전 Recall/NDCG 수치를 새 데이터의 성능으로 옮겨 적지 않는다.

원본 크롤링이 미완료이며 출처별 중복과 날짜 정밀도 차이가 남아 있다.
[적재·품질 기록](./2026-09-26_crawler_import.md)에 수집 범위와 확인된
제한을 정리했다. 현재 규모를 다시 확인하려면 `rating-recsys-dataset`과
`queries/compare_crawl_sources.sql`을 실행한다. 모델 성능은 같은 DB
스냅샷으로 `rating-recsys-experiment`를 다시 실행해 판단한다.
