## 9. 판정과 독립 검증

**이번 프로필·모델 조건은 후보 Recall@100 기준으로 채택하지 않고 기존 C5를 유지한다.**
검증으로 고른 C1+C4+임베딩 RRF는 임베딩 관련 세 정책 중 최선이며, 기존 C5까지 포함한 최선의 정책이라는 뜻은 아니다. Test Recall@100은 C5 20.1626%, 임베딩 단독 3.2757%, 결합 16.5637%다. 결합의 C5 대비 차이는 −3.5989%p이며 paired bootstrap 95% 구간은 −4.4422~−2.8003%p다.

결합 후보 순서의 NDCG@10은 0.028920으로 C5 순서 0.026590보다 높았지만 후보 Recall@100은 낮았다. 이 값은 후보 목록 앞부분의 순위 지표이며 새 후보로 LambdaRank를 학습한 최종 추천 성능은 아니다. 이번 하나의 리뷰 프로필 실험으로 텍스트 전체의 효과를 판정하지 않는다.

- 저장된 후보 1,580개 query를 점검했다. 후보 100개 이하·중복 없음·방문 식당 제외·T2 시점 catalog 범위가 모두 일치했다.
- 만족 정답이 있는 사용자 1,573명에 대해 Recall@100을 독립 재계산했다. 정답이 없는 7명은 기존 지표 규칙에 따라 제외했고, 임베딩 프로필이 없는 사용자를 따로 성능 모수에서 제거하지 않았다. 세 정책의 저장된 지표가 모두 일치한다.
- 같은 snapshot의 history-aware Window baseline에서 C5 Recall@100도 일치했다. 독립 점검 결과는 `audit.json`에 저장했다.
- 전체 회귀 테스트 120개가 통과했다. 이후 보고서에 API 사용량 표를 추가하고 관련 20개 테스트도 통과했다.
- 다음 텍스트 후보 비교는 BM25다. 이번 test를 보고 임베딩 설정을 최적화한 성능으로 해석하지 않는다.
