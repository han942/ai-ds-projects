# 개인별 만족도 기준과 Window baseline

기준일: 2026-10-04. **개인별 기준은 과거 이력 10건부터 적용한다.** 이력이 적으면 기존
절대 등급을 쓰고, 충분하면 강한 만족 경계를 사용자 과거 평균에 맞춰 제한적으로 조정한다.
이 기준을 고정한 뒤 C5 + LambdaRank를 Window 방식으로 학습·평가한다.

## 최소 이력을 10건으로 정한 근거

고정 snapshot `e7896add5b4b5939`의 **T1(2025-12-19)까지 train 70,883행,
사용자 11,655명**만 분석했다. Validation/test 평점과 추천 성능은 기준 선택에 사용하지 않았다.
이력 수는 전처리 후 서로 다른 식당에 대한 최초 방문·평점 수다. 같은 식당의 중복 리뷰 수가 아니다.

사용자별 train 이력의 중앙값은 2건, 75백분위는 6건, 90백분위는 16건이다.
사용자 평균 차이를 제외한 사용자 내 pooled 표준편차는 **0.6495점**이다.
표본 평균의 정밀도를 `1.96 × 표준편차 / √이력 수`로 근사해 비교했다.

| 최소 이력 | Pooled 근사 오차 폭 | 사용자별 오차 폭의 90백분위 | 개인 기준 적용 가능한 train Window query |
|---|---:|---:|---:|
| 5건 | ±0.569점 | ±0.784점 | 12,491 / 19,158 (65.2%) |
| 8건 | ±0.450점 | ±0.642점 | 9,616 / 19,158 (50.2%) |
| **10건** | **±0.403점** | **±0.570점** | **8,196 / 19,158 (42.8%)** |
| 15건 | ±0.329점 | ±0.455점 | 5,569 / 19,158 (29.1%) |

Pooled 값은 모든 사용자 내 표본 분산을 자유도로 가중한 값이다. 사용자별 90백분위는
각 사용자 train의 첫 n건에서 구한 표본 표준편차로 계산하며, n건 이상 있는 사용자가 대상이다.
Query 적용률은 모델이 학습에 사용할 group을 선별하기 전 모든 train Window query 기준이다.
한 사용자가 여러 기간에 참여하므로 사용자 비율과 같지 않다.

**판단:** 10건은 5·8건보다 평균의 불안정성을 줄이면서 15건보다 많은 시점에 개인 기준을
적용할 수 있는 절충안이다. 10건 시점의 사용자별 오차 폭 중앙값은 ±0.352점이다.
이력이 적은 사용자를 제외하지 않고 절대 기준으로 평가한다.

이 오차 폭은 독립 관측을 가정하는 정밀도 진단이며 보장된 95% 신뢰구간이 아니다.
평점은 범위가 제한되고 반점 단위이며, 방문 간 의존·취향 변화·상수 평점 이력이 있다.
Pooled 분산에는 활동이 많은 사용자의 영향이 크다.
Train 방문 40건 이상인 동일 사용자 273명의 첫 10건과 다음 10건 평균 차이는
중앙값 0.20점, 90백분위 0.60점이었다. 이는 시간 변화의 보조 진단이며 전체 사용자로 일반화하지 않는다.
10건은 성능을 최대화하도록 탐색한 값이나 최적의 통계적 경계라고 주장하지 않는다.

## 적용한 정답 규칙

각 query의 추천 cutoff 이전 사용자 평점만으로 이력 수 n과 단순 평균 μ를 구한다.
미래 방문·평점은 μ에 넣지 않는다. 평균 feature의 shrinkage는 기존 값 λ=0으로 유지한다.

| 과거 이력 | 강한 만족 경계 h | 약한 만족 경계 |
|---|---|---|
| n < 10 | 4점 | 3점 |
| n ≥ 10 | `clip(4 + 0.5 × (μ − 4), 3.5, 4.5)` | 3점 |

| 실제 미래 평점 r | Label | LambdaRank gain |
|---|---:|---:|
| r ≥ h | 2 | 3 |
| 3 ≤ r < h | 1 | 1 |
| r < 3 | 0 | 0 |

가중치 0.5는 기존 4점과 개인 평균을 절반씩 반영한다. 최대 이동 0.5점은 평점 성향이
강한 사용자도 강한 만족 경계가 3.5~4.5점을 벗어나지 않도록 제한한다.
두 값은 과제 정의를 위한 보수적인 설정이며 validation/test 점수로 최적화하지 않았다.

| 예시 | 적용 경계 | 미래 평점의 등급 |
|---|---|---|
| 이력 9건, 과거 평균 3점 | h=4 | 3.5점은 약한 만족 |
| 이력 10건, 과거 평균 3점 | h=3.5 | 3.5점은 강한 만족 |
| 이력 10건, 과거 평균 4.6점 | h=4.3 | 4점은 약한 만족, 4.5점은 강한 만족 |
| 이력 10건, 모두 5점 | h=4.5 | 4.5점 이상은 강한 만족 |

분산으로 나누지 않으므로 상수 평점 이력도 처리된다. 낮은 평균이어도 3점 미만은
등급 0으로 유지한다. 사용자 평균이 높아도 경계의 상한은 4.5여서 강한 정답이 도달 불가능해지지 않는다.

이번 개인화는 **약한/강한 만족의 구분**을 바꾼다. Positive(등급 > 0)의 절대 경계는
계속 3점이므로 같은 후보의 Recall은 이 규칙만 바꿔도 동일하다. NDCG는 등급별 gain을
반영하므로 이전 절대 등급의 NDCG와 직접 비교할 수 없다. 4점 이상 Recall과 3점 미만
방문의 Top-K 포함 수·비율은 별도 절대 평점 진단으로 기록한다.
관측되지 않은 후보의 학습 label도 0이지만 실제 낮은 평점을 받았다는 뜻은 아니다.

## 학습·선택·평가 절차

1. 기존 snapshot과 전역 T1/T2를 고정한다. Test를 고평점 기준으로 필터링하지 않는다.
2. 기본 3개월 Window의 시작 전 이력으로 후보 100개와 feature를 만들고, 기간 내 모든 방문을 정답으로 묶는다.
3. 같은 개인별 기준으로 train label과 validation 정답을 만든다. 후보에 정답을 강제로 넣지 않는다.
4. 기존 LambdaRank 7개 설정을 validation end-to-end Graded NDCG@10으로 비교한다.
5. 선택한 설정·트리 수를 고정하고 T2까지 Window를 재구성해 학습한 후 test를 한 번 평가한다.
6. 개인별 평균·적용 여부·경계는 `queries_*.jsonl`, 적용 사용자 수와 등급 분포는 manifest에 저장한다.

학습 기간은 3개월, test 기간은 약 145일이므로 기간 길이가 완전히 같지는 않다.
신규 사용자처럼 cutoff 이전 이력이 없는 사용자는 기존 개인화 평가 범위에서 제외되고 별도 집계된다.
이미 사용한 snapshot의 test이므로 이 실행은 새 기준의 기준값이며, 새 미래 holdout의 일반화 검증은 아니다.

## 재현

프로젝트 Conda 환경의 Python을 사용한다. 기존 CLI 기본값은 과거 재현을 위해
`prefix/absolute`로 유지하며, **이번 baseline은 아래 옵션을 명시한다.**

```bash
python scripts/analyze_rating_history.py

rating-recsys-experiment \
  --snapshot artifacts/snapshots/e7896add5b4b5939.jsonl \
  --ranker-training-mode window \
  --ranker-label-mode relevance \
  --satisfaction-mode history-aware \
  --satisfaction-min-history 10 \
  --satisfaction-mean-weight 0.5 \
  --satisfaction-max-shift 0.5 \
  --label window-personal-satisfaction-n10
```

분석 원본은 [`scripts/analyze_rating_history.py`](./scripts/analyze_rating_history.py),
상세 수치는 로컬 `artifacts/analyses/rating_history/analysis.json`에 있다.
Snapshot·cutoff·개인별 규칙·전처리 변경 시 prepared 데이터가 무효화된다.
별점 예측값은 출력하지 않으므로 MAE/RMSE는 이 baseline에 적용하지 않는다.

## 실행 결과

**2026-10-04 전체 실행 완료.** Snapshot·seed 42·C5 구조를 유지하고,
validation에서 leaves 63 / min_child_samples 100 / trees 76을 선택했다.
튜닝용 group 7,123개, 최종 refit group 8,043개(804,232 feature rows)다.
Window 학습·후보 생성·평가에 1,070.3초(약 17.8분)가 걸렸다. MLflow에 저장했다.

| 지표 | Validation | Test |
|---|---:|---:|
| 후보 Recall@100 | 19.4769% | 20.1626% |
| R1 Graded NDCG@10 | 0.027694 | 0.025467 |
| R1 Recall@10 | 4.1667% | 3.6502% |
| R1 4점 이상 Recall@10 | 4.1145% | 3.5105% |
| R0 후보 순서 NDCG@10 | 0.023311 | 0.026590 |

Test의 cutoff 이전 이력 사용자 1,580명 중 **862명(54.6%)은 개인 기준**, 718명은
이력 부족으로 절대 기준을 적용했다. 등급 > 0 방문이 있는 1,573명으로 주 순위 지표를
집계했고, 등급 0 방문만 있는 나머지 7명도 원자료와 저평점 진단에 보존했다.
절대 기준 대비 미래 방문의 등급이 달라진 행은 676개다. Label 0/1/2는 43/1,376/4,246개다.
이는 입력 이력·후보를 바꾼 것이 아니라 정답 등급을 바꾼 것이다.

실제 3점 미만 미래 방문 43개 중 Top-10에 포함된 것은 **3개(6.98%)**다.
이 비율의 분모는 관측된 낮은 평점 방문이며 전체 추천 항목이나 미관측 식당이 아니다.
4점 이상 Recall@10은 해당 미래 방문이 있는 사용자 1,510명의 macro 평균이다.

**해석:** 이번 test에서 R1 NDCG@10은 R0보다 0.001124 낮았다. 사용자별 paired bootstrap
2,000회의 차이 95% 신뢰구간은 **[−0.005053, +0.002694]**로 0을 포함한다.
Validation의 재정렬 개선이 test에서는 이어지지 않았으며, 재정렬이 효과적이라고
확인한 결과는 아니다. 선택된 R1과 R0를 함께 보존하고 test 결과로 설정을 다시 고르지 않았다.
이전 Prefix/절대 등급의 NDCG 0.029360과는 과제가 달라 직접 비교하지 않는다.

**검증:** 전체 테스트 114개 통과. 저장된 snapshot·이력·미래 방문·추천·후보 순위로
개인 기준과 validation/test NDCG·Recall·절대 평점 진단을 독립 재계산했으며 모두 일치했다.
모든 이력 사용자 미래 방문을 보존했고, 미래 평점을 과거 평균에 넣지 않았으며,
과거 방문 식당을 추천 목록에서 제외했음을 확인했다.
