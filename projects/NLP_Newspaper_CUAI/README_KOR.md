# CUAI NLP 프로젝트 (2025.03.01 ~ 2025.07.03)

[English](./README.md)

## GOAL

아이들과 청소년들은 어려운 성인용 뉴스 기사를 잘 읽지 않습니다. 이 프로젝트는 **어려운 시사 뉴스를 초등학교 고학년~중학생 눈높이에 맞게 쉬운 언어로 재작성**하여, 아이들이 하드 뉴스(hard news)를 더 많이 접하고 이해할 수 있도록 돕는 것을 목표로 합니다.

합성 병렬 데이터 구축부터 QLoRA 파인튜닝, 추론, 한국어 기반 재평가까지 구현했습니다. 저장된 출력에서 드문 어휘와 문장 단위의 길이가 줄고, 원문 복사보다 합성 참조문에 가까운 재작성을 확인했습니다. 근거와 수치는 [평가 결과](#평가-결과)에 정리했습니다.

CUAI(대학생 AI 연합 동아리) NLP 1팀 최종 프로젝트입니다. 2025년 7월 1일 발표되었습니다.

## 데이터셋

- **원천 데이터**: 국립국어원 신문 말뭉치 + 일상 대화 말뭉치
- **문제점**: 성인용 뉴스와 아동용 쉬운 버전이 짝지어진 병렬 코퍼스가 존재하지 않음
- **해결 방법**: ChatGPT API를 이용해 병렬 데이터를 합성 생성

  > "다음 문장을 초등학교 고학년~중학생이 쉽게 이해할 수 있도록 바꿔주세요. 원래 의미는 유지하되, 쉬운 단어를 사용하고, 복잡한 개념은 간단히 풀어서 설명해주세요."

- **데이터 규모**: 총 15,894쌍 (Train 70% / Validation 15% / Test 15%)
- **예시**
  - 원문: "인천 청라시티타워 '운명의 날'…내일 추진 여부 결정"
  - 변환: "인천 청라시티타워의 중요한 날이 다가왔어요. 내일 이 건물을 계속 만들지 결정할 거예요."

## 모델 & 학습

- **베이스 모델**: `google/gemma-3-1b-it` — Gemma 2 대비 더 긴 컨텍스트를 지원하는 경량(1B) 모델로, 성능과 자원 제약 사이의 균형을 고려해 선택
- **파인튜닝 방법**: QLoRA(4-bit NF4 양자화, bf16 연산) + LoRA(`r=64`, `lora_alpha=16`, `dropout=0.1`, target modules: q/k/v/o_proj, gate/up/down_proj), `trl`의 `SFTTrainer` 사용
- **학습 설정**: 5 epochs, batch size 1, gradient accumulation 8, `paged_adamw_8bit` optimizer, lr=2e-4, cosine scheduler, bf16, 총 800 steps까지 학습 (50 step마다 체크포인트 저장)
- **프롬프트 포맷** (Gemma 챗 템플릿)

```
<start_of_turn>user
다음 뉴스를 초등학생이 이해하기 쉽게 간단하게 바꿔줘: {원문}<end_of_turn>
<start_of_turn>model
{변환된 문장}
```

## 평가 결과

**Gemma 파인튜닝 모델의 저장된 출력 2,340건**을 재평가해, 원문 복사보다 합성 참조문에 가까운 재작성과 어휘·문장 구조의 단순화 경향을 확인했습니다. 아래는 기존 파인튜닝 결과의 성과이며, 후속 에이전트의 평가 결과와는 구분합니다.

| 강점 | 확인한 근거 | 해석 |
|---|---|---|
| 원문 복사를 넘어서는 재작성 | 한국어 형태소 SARI **58.80**, 원문 복사 **46.46**, 무작위 출력 **32.67** | 합성 참조문에 가까운 어휘 편집을 수행함 |
| 어휘와 문장 구조의 단순화 | 드문 명사 비율 **7.3% → 4.1%**, 문장당 어절 수 **15.91 → 13.89** | 빈도가 낮은 어휘와 문장 단위의 길이가 줄어듦 |
| 원문의 구체적인 정보 유지 | 숫자 값 재현율 평균 **87.5%**, 고유명사 재현율 **91.6%** | 자동 검출된 원문 정보를 상당 부분 유지함 |

드문 명사는 어휘 빈도로 정의하며, 재현율은 숫자·고유명사가 검출된 행의 값을 평균한 수치입니다. 실제 독자의 이해도나 사실 정확성을 직접 측정한 값은 아닙니다. 형태소 SARI의 원문 복사 대비 차이는 **12.34점**이며, 대응 행 bootstrap 95% 구간은 **11.90–12.78점**입니다.

전체 비교와 신뢰구간, 사례는 [재평가 보고서](evaluation/REPORT.md), 재현 방법은 [평가 실행 안내](evaluation/README.md)에 정리했습니다.

## 한계점

- 자연스러운 출력에도 숫자 누락이나 조건의 의미가 뒤집히는 사례가 있어 사실 보존 검수가 필요함
- 합성 참조문에도 오류가 있을 수 있으며, 대상 독자의 실제 이해도는 직접 측정하지 않음
- 동일 조건의 미세조정 전 출력이 없어 파인튜닝 자체의 개선 효과는 분리해 평가할 수 없음. 자원 제약으로 하이퍼파라미터 탐색도 제한적으로 수행함
- 기존의 “SARI 40점 이상이면 우수”라는 기준은 무작위 출력도 47.14를 받아 성능 근거로 사용할 수 없음. 영어용 FKGL 역시 한국어 읽기 학년으로 해석할 수 없음

## 실행 환경

```bash
pip install -r requirements.txt
cp .env.example .env
```

- **Python 3.12** 기준(노트북은 3.12.3에서 실행됨). 라이브러리 버전은 pin되어 있지 않으며, 노트북 내 `!pip install -U`가 최신본을 설치합니다.
- 노트북은 Gemma 3 1B에 대한 4-bit QLoRA 파인튜닝을 수행하므로 CUDA 지원 GPU가 필요합니다. `bitsandbytes`는 CUDA toolkit이 설치된 Linux/WSL 환경을 전제로 합니다.
- `google/gemma-3-1b-it` 다운로드를 위해 Hugging Face access token(이 프로젝트의 `.env` 또는 `huggingface_hub.login`)이 필요합니다.
